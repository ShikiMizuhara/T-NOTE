# T-NOTE

T-NOTE 是一款适用于 Windows 的本地 Markdown 笔记软件。暗色终端界面搭配金色线条与荧光点缀，让日常记录、学习笔记和技术文档拥有一个独特的写作空间。

无需注册，无需联网。你的笔记就是电脑上的普通 `.md` 文件，随时可以打开、复制和备份。

## 下载与安装

适用于 **Windows 10 / 11，64 位系统**。

1. 打开本仓库的 **Releases（发行版）** 页面。
2. 下载 `T-NOTE-Setup-版本号.exe`。
3. 双击安装包，按提示完成安装。
4. 启动 T-NOTE，选择一个本地文件夹作为笔记书库。

安装后即可使用，不需要安装 VS Code、Node.js 或其他开发工具。下载时请选择 `.exe` 安装包。

## 功能亮点

- **边写边看**：左侧编辑 Markdown，右侧实时预览排版效果。
- **长段落自动折行**：文字到达编辑区边缘后自动折到下一排，不改变实际文本内容，也不增加行号。
- **书籍分类与搜索**：用文件夹分类笔记，快速查找、重命名或移动文件。
- **自动保存**：停止输入后自动保存，也可以按 `Ctrl + S` 手动保存。
- **常用格式快捷按钮**：快速插入标题、加粗、斜体、链接、代码、列表、引用和待办事项。
- **代码高亮与复制**：支持多种常见编程语言，可在预览中切换代码块语言、复制代码。
- **直接勾选待办**：点击预览中的复选框，同步更新笔记内容。
- **本地图片**：支持在笔记中引用书库里的图片。
- **删除可找回**：删除的笔记会移入书库回收文件夹。

## 开始写第一篇笔记

选择书库后，点击左侧 **NEW DOCUMENT** 新建笔记。

在左侧编辑区输入内容，右侧会自动显示排版结果。

你可以用编辑区上方的按钮插入常用格式，不必记住所有 Markdown 语法。

## 整理你的书库

“书库”就是首次打开软件时选择的文件夹；“书籍”就是这个文件夹中的一级子文件夹。

- 点击 **＋ BOOK** 创建书籍分类。
- 点击书籍名称，查看该分类下的笔记。
- 点击 **RENAME** 重命名当前笔记。
- 点击 **MOVE** 将当前笔记移动到其他书籍。
- 点击 **LOCATE** 在文件管理器中定位当前笔记。
- 点击 **CHANGE LOCATION** 切换书库文件夹。

未放入书籍的笔记会显示在“未分类 / 根目录”中。当前支持一级书籍分类，不支持多层嵌套。

## 在笔记中插入图片

软件会在书库中自动创建 `assets` 文件夹，用于存放图片等附件。它不会作为书籍显示在索引里。

先将图片复制进 `assets`，再在笔记中填写图片路径。

如果笔记位于书库根目录：

```markdown
![图片说明](assets/photo.png)
```

如果笔记位于某本书籍的文件夹中：

```markdown
![图片说明](../assets/photo.png)
```

支持 PNG、JPEG、GIF、WebP 和 AVIF 图片。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Ctrl + S` | 保存当前笔记 |
| `Ctrl + N` | 新建笔记 |
| `/` | 不在输入框中打字时，快速进入搜索 |
| `Tab` | 在编辑区插入两个空格 |

## 常见问题

### 笔记保存在哪里？

笔记保存在你选择的书库文件夹中，以普通 `.md` 文件保存。软件不会将笔记上传到服务器。

### 为什么重新安装后会打开原来的文件夹？

软件会在当前电脑上记住上次选择的书库。这个记录保存在本机，不在安装包中；其他人安装时会自行选择自己的书库。

### 删除的笔记在哪里找回？

打开书库文件夹，在 `.neonote-trash` 目录中找到被删除的笔记，复制或移动回根目录或对应的书籍文件夹即可。

### 可以用其他软件编辑笔记吗？

可以。笔记是普通 Markdown 文件，可用其他编辑器打开。T-NOTE 会检测外部修改；如果与尚未保存的内容发生冲突，会提示你确认是否覆盖。

### 怎么备份笔记？

复制整个书库文件夹即可，记得一起保留 `assets` 中的附件。
